# 🚩 Flagged

**Flagged** is an intelligent reporting and moderation application designed to streamline the process of identifying, flagging, and managing user reports, incidents, or restricted content in real time. 

---

## ✨ Features

- **Real-Time Reporting:** Submit and categorize flags or incidents instantly with geospatial or contextual tagging.
- **Moderation Dashboard:** A dedicated interface for reviewers and admins to review, verify, prioritize, and resolve flagged items.
- **Status Tracking:** Track the lifecycle of a flag from submission to investigation and final resolution.
- **User-Friendly Interface:** Clean, responsive, and modern UI built for fast-paced operational workflows.
